# Ontario administrative boundary

`ontario.geojson` contains the Ontario feature extracted from the simplified
geoBoundaries gbOpen CAN ADM1 dataset at upstream revision `41af8f1`. Geometry and
feature properties are unchanged; only the surrounding collection and formatting
were changed. The full source and output SHA-256 hashes are in `ontario.source.json`.

geoBoundaries distributes gbOpen under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The upstream metadata identifies Statistics Canada as the source and reports
Open Government Canada 2.0 / the [Statistics Canada Open Licence](https://www.statcan.gc.ca/en/terms-conditions/open-licence).
These data keep their own terms; the ARCES MIT code license does not replace them.

Source: Statistics Canada, provincial/territorial boundary data, distributed through
geoBoundaries CAN ADM1 (metadata reference year 2023). Adapted for ARCES; this does

Runfola, D. et al. (2020). geoBoundaries: A global database of political administrative
boundaries. PLoS ONE 15(4): e0231866. https://doi.org/10.1371/journal.pone.0231866

[geoBoundaries](https://www.geoboundaries.org/). This is a simplified boundary for
exploratory cell-centre selection; no land mask or survey-grade boundary is implied.
