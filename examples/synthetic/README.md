# Synthetic demonstration

These are generated test outputs, not NASA observations. The data contains 15
complete years (2000–2014), 12 months per year, with an intentionally exact
1 degree C/decade warming trend. Its almost-zero uncertainty is a consequence of
the constructed data, not evidence about the real climate.

Open `report.html` locally to inspect the chart and links to the CSV/JSON outputs.
Run `scripts/demo.ps1` from the project root to generate a new example yourself.
