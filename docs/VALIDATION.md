# Validation record — 0.3.0 development milestone

Verified locally on Windows x64 with MSVC 19.44.35230, CMake 4.4.4, NetCDF 4.9.3,
and Boost Math 1.92.0. Both Debug and Release builds completed successfully.

## Automated verification

All seven CTest groups passed in both configurations:

1. `cli_errors`: expected errors and exit codes for invalid input.
2. `create_netcdf_fixture`: a real NetCDF-4 fixture generated by the library.
3. `read_netcdf_fixture`: successful location/temperature/time extraction.
4. `timestamp_conversion`: boundaries, leap years, invalid formats, and overflow.
5. `annual_and_trend_calculations`: coverage, weights, duplicates, fixed-grid
   checks, known slopes, constant data, output escaping, and reference statistics.
6. `create_series_fixture`: synthetic multi-file and malformed-data fixtures.
7. `series_csv_and_trend`: full CLI pipeline, missing months/values, valid-range
   rejection, packed temperatures, date windows, wrong shapes/units, duplicates,
   changing grids, and preservation of existing outputs.

For the independent 12-year noisy reference, the implementation matched:

| Quantity | Reference |
|---|---:|
| Slope (C/year) | 0.8426573426573427 |
| HAC slope SE (C/year) | 0.05174655941608503 |
| 95% lower (C/year) | 0.7273588231657477 |
| 95% upper (C/year) | 0.9579558621489377 |
| Approximate p-value | 1.583822667537093e-8 |
| R squared | 0.9045898422290405 |

A second exact-rational reference checks that HAC lagging respects calendar-year
gaps. These comparisons validate calculations, not the assumptions of any real
climate case study. See `tools/reference_stats.py` and `docs/METHODS.md`.

## Demonstration and delivery

The demo generated 180 synthetic monthly records over 2000–2014. The analysis
recovered the deliberately constructed 1 C/decade slope and exported CSV, JSON,
HTML, and SVG outputs. The example HTML was rendered in headless Chrome and
visually inspected. Synthetic example source paths were made relative for sharing.

The GitHub workflow was updated to run these tests in Debug and Release. It has
not been pushed or run on GitHub as part of this local update. Local changes are
on `feature/trend-analysis`; the original pre-update source was backed up separately.
